## 0. 核心原则

> **看得见的，去申请；看不见的，当商业秘密；不想被别人抢的，防御性公开。**

单押一件「§8 图像相关 OGV 调用」专利**不够**，三个结构性原因：
1. **能拿到的 claim 窄、好绕** — 宽 claim 撞 HP US8873102 + 学术 IDGM 的新颖性；窄到「语义分割驱动」则竞品改用直方图触发即可避开。
2. **看不见 → 测不到侵权（最致命）** — 分离算法跑在竞品软件内部、只吐印张，外部无法举证侵权；而专利还要求公开揭露 → 交出秘方却抓不到抄者。**对隐形算法，专利常是错的工具。**
3. **只护差异化、不护产品** — 客户换软件是为整套工作流/体验/质量，竞品可照抄 UX + 简单分离法，绕过 §8 抢市场。

→ 正解是**组合拳**：窄专利丛护「看得见的」+ 商业秘密护「看不见的算法」+ 数据/工作流当真护城河。

## 2. §101 适格性（美国 Alice）框定

纯数学/抽象算法易被 §101 驳回。**所有专利请求项框成「一种控制印表机/印製的方法或系统」**，绑物理过程：

> 分析图像 → 决定油墨分配/调用 → **驱动打印头沉积油墨 → 输出实体印张**

- 强调技术效果：扩大可印色域、减少 banding、提高 ΔE 准确度（**对印刷技术的具体改进**），而非「计算一个数」。
- 加入硬件限定（PRO12 油墨族、i1Pro3 测量、PJL 直送光栅）增强适格性与区隔度。

## 3. §8（A5）申请前的新颖性预检索清单

申请前**必做**，确认「语义记忆色分割 → 分区扩展色油墨调用」这一特定组合未被抢先；并据此决定 claim 宽窄与区隔写法。

### 3.1 必查的现有专利（先区隔，再决定能否拿宽 claim）
- [ ] **HP US8873102**（动态分离/已查）— 区隔点：它「**机上依实际装墨动态**」且**无语义分割**；§8 是**离线建档 + 主机端 + 语义分区**。**A5 claim 必须把「语义分割/分区」写进独立项**，否则撞它。
- [ ] **Agfa US8054504 / US7265870**（Mahy，多色分离/已查/待查）— 区隔点：它是「对立墨/封闭曲面/双 4 色子流程」特定策略；§8 是全 N 墨 ΔE 反演 + 图像相关。
- [ ] **Onyx US9373063**（同色相拆分/已查）— 属 (A) 域，非 §8，但确认 A3/black_split 不落其 PVR 法。
- [ ] 检索 IPC/CPC：**H04N1/60**（色彩处理/分离）、**G06K15/02**、**B41J2/21**（多墱喷印）下，关键词 image-dependent / content-dependent / segmentation + ink separation / gamut。
- [ ] Google Patents 按权利人扫：HP、Canon、Epson、Agfa/Eco3、Onyx、EFI/Fiery、GMG、ColorLogic、Xerox —— 这些最可能持「图像相关分离」专利。

### 3.2 必查的学术 prior-art（可能毁掉宽 claim，也是你区隔的弹药）
- [ ] **Image-Dependent Gamut Mapping (IDGM)** 文献（Morovic、Montag、Bonnier 等）—— 泛泛「图像相关 gamut mapping」是已知研究，**A5 不能泛泛主张**；novelty 必须落在「**驱动扩展色油墨（O/G/V）调用**」+「**记忆色语义分割**」这个**特定窄组合**上。
- [ ] **Semantic segmentation for color/print** + memory-color preservation 文献。
- [ ] Mahy《Inversion of the Neugebauer Equations》及后续 —— 确认仅覆盖通用反演（= 你能自由用的 prior-art），不涉图像相关调用。
- [ ] 多通道/扩展色域 separation 综述（确认「按图调用 OGV」无明确在先公开）。

### 3.3 检索结论 → claim 策略（预案）
- **若 §8 特定组合干净** → 申请：独立项 = 「**记忆色语义分割 → 分区指定 intent/强度 → 分区调用 O/G/V 扩展油墨**的印製方法」；从属项 = CoreML 实现 / OGV 调用率反馈 / A/B 决策。
- **若被泛 IDGM 挡** → 退到更窄：绑定具体记忆色类（肤/天/植）+ 具体 O/G/V 通道分配 + 调用率 meter 闭环；并把保护重心移到 **A1–A4（可举证）+ S1（商业秘密）**。
- **无论宽窄** → §8 核心数值逻辑（S1）仍留商业秘密，专利只覆盖「**可被观察到的方法/UI 行为**」。

### 3.4 工程侧初筛结果（2026-06，⚠ 非检全、非法律意见）

**🔴 决定性发现 — 直接命中、且是竞品：[US12034903](https://patents.google.com/patent/US12034903) · Fiery LLC（EFI Fiery，RIP 竞品）· 活跃 → 2043（2023-10 申请）**
- claim 1：**语义分割 → 提取物件 → 为物件指派「专色/品牌色」（Pantone/logo）** → 输出 spot color 层 + 制程墨。
- **不涉**：扩展色域油墨（O/G/V）、记忆色（肤/天/植）、分区渲染意图、连续 gamut 扩展。
- **双重含义**：
  1. **封死了 §8 的「宽 claim」** —— 泛泛「RIP 里语义分割 → 按物件做色彩处理」已被 Fiery 抢先（2023），jcolour **拿不到宽版**。
  2. **§8 仍可拿「窄版」** —— jcolour 的区隔是 **(i) 记忆色类（非品牌专色）+ (ii) 分区渲染意图/强度 + (iii) 连续调用 O/G/V 扩展【制程墨】（非离散 spot color 映射）+ (iv) OGV 调用率 meter 闭环**。这四点 US12034903 全无 → 特定组合**大概率干净**。
  3. **同时是 FTO 项** —— §8 落地须**避开**「为检测物件指派离散专色」这一动作（jcolour 做的是 intent/OGV 制程墨，本就不同 → 应可区隔，但须律师核 claim）。

**🟢 基础扩展色域专利已过期（prior-art，可用 + 可用来打竞品过宽 claim）**：首件扩展色域专利 1968（Dainippon Screen）、1985（Kueppers）—— 早过期。「CMYK 在橙/绿/紫有缺口、加 O/G/V 主色扩 gamut」是数十年公开概念，**任何人都无法就这个泛概念拿专利**。

**🟢 油墨/主色设计类无关 jcolour 软体**：US20150158317、US8011775、GB2527495（ink set 优化/化学）等 —— 不沾分离算法。

**🟡 学术 IDGM = 已知 prior-art**：Image-Dependent Gamut Mapping（Morovic《Color Gamut Mapping》等）确立「图像相关 gamut mapping」为公开领域 → 再次印证 §8 **不能泛主张**，novelty 必须落在上面 (i)–(iv) 的窄组合。

**初筛净结论**：
- §8（A5）**宽 claim 已被 Fiery US12034903 + 学术 IDGM 封死**；
- §8 **窄 claim（记忆色分割 → 分区 intent/强度 → 连续 O/G/V 制程墨调用 + 调用率 meter）大概率仍可拿**，但价值有限、且须先做 FTO 确认不落 US12034903；
- **战略重心应进一步前移到 A1–A4（可举证的外壳）+ S1–S3（商业秘密内核）** —— 一个 RIP 竞品已在这块抢跑，单靠 §8 窄专利护不住，**商业秘密 + 数据/工作流护城河更关键**（印证 §0 结论）。
- **待律师补全**：US12034903 全 claims 的 FTO 读；US9767397 / US8711429 / US7265870 / US7164498 状态与 claim；Esko/EFI/Canon/Epson 按权利人全扫；Morovic IDGM 文献的具体公开点。

## 4. 真护城河（提醒：IP 只是一环）

对藝術微噴 RIP，长期壁垒多半**不是专利**：
1. **数据/校准网络效应** — 累积的纸张标准库 + 实测 profiles + §6 云端 profiling 管线，竞品复制不了。
2. **工作流锁定 + UX + 执行品质** — 客户为整套体验付费/留存。
3. **云端侧秘密** — AGPL 隔离 + 你的参数，留服务器端。

→ 专利预算优先级：**A1–A4（可举证、护外壳）> A5（差异化、但先检索）**；算法内核走商业秘密；架构原则防御性公开。
