# STACK.md - Technology Stack for Personal Development Environment

## Core Technologies

- **macOS**: Operating system providing Unix-based development environment
- **Shell**: Zsh as primary shell with Oh-My-Zsh framework
- **Development Tools**: Git, Homebrew, Node.js, Python, Bun
- **Terminal**: iTerm2 for enhanced terminal experience

## Development Environments

- **Claude Code**: AI-assisted development environment
- **Cursor**: AI-powered code editor
- **VS Code**: Standard code editor with extensions
- **Ollama**: Local LLM runner for offline AI capabilities

## AI Tooling Stack

- **Claude API Integration**: Anthropic Claude models access
- **OpenAI Integration**: GPT models access
- **Ollama**: Local open-source models (Llama, Mistral, etc.)
- **AI Experimentation Tools**: Various AI SDKs and frameworks

## Package Management

- **npm/yarn/pnpm**: JavaScript/Node.js package management
- **Python pip**: Python package management
- **Homebrew**: macOS system-level package management
- **Bun**: Fast JavaScript runtime and package manager

## Development Infrastructure

- **Docker**: Containerization for consistent environments
- **SSH Keys**: Secure remote access management
- **Git**: Version control system with GitHub integration
- **Local Servers**: Built-in macOS services and custom configurations

## Cloud Services Integration

- **GitHub**: Source code hosting and CI/CD
- **Various AI APIs**: External AI service integrations
- **Cloud Storage**: Sync and backup solutions

## Experimental Frameworks

- **OpenClaw**: AI agent framework
- **Claude Code Extensions**: Custom skill development
- **Automation Scripts**: Python, Shell, JavaScript
